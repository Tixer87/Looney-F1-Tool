StintsRaw, notes:

Format Structure
Each stint: {tyre_type}:{laps}:{wear_start}:{wear_end}
Parameters:
•	tyre_type (required): Numeric value from TyreType enum
•	laps (required): Number of laps completed on this tire compound
•	wear_start (optional): Tire wear at stint start (0-100)
•	wear_end (optional): Tire wear at stint end (0-100)
TyreType Numeric Values
Common tire types:
•	0 = Soft
•	1 = Medium
•	2 = Hard
•	3 = Intermediate
•	4 = Wet
•	5 = SuperSoft
•	6 = UltraSoft
•	7 = HyperSoft
•	11-16 = C1-C6 compounds
•	20 = Option
•	21 = Prime
•	22 = Qualifying

Examples:
"StintsRaw": "1:25::,0:18:0:95,2:12::"
"StintsRaw": "1:22:0:68,0:20:0:89,2:13:0:72"
